# ONE-107 (форк): русский каталог ядра Twenty

Ветка `one-107-ru-translations` форка `salxDev97/twenty`. Парная ветка в
`Pineap-inc/onema-os` — `one-107-russian-ui` (язык по умолчанию, подписи
приложения, скрипты); там же общий хендовер задачи.

## Зачем

Требование владельца Onema от 2026-10-12: «абсолютно все тексты, анимации и
т. д. должны быть на русском», перенесено из «после запуска» в «до запуска».
Половина строк интерфейса приходит из ядра Twenty — из каталогов lingui,
поэтому эта часть задачи живёт в форке.

## Что сделано

### 1. Заполнены пустые и непереведённые строки

| Каталог | Было пустых | Было «перевод = исходник» | Стало пустых |
| ------- | ----------- | ------------------------- | ------------ |
| `twenty-server` | 40 | 6 | 0 |
| `twenty-front`  | 44 | 72 | 5 |
| `twenty-emails` | 0  | 0  | 0 |

Пять оставшихся пустыми строк фронта — псевдонимы команд текстового
редактора (`ol`, `ul`, `p`, `ordered`) и `CRUD`: пользователь набирает их
латиницей, перевод сделал бы их нерабочими. Они перечислены в списке
исключений, и проверка о них знает.

Строки вида «перевод = исходник», оставшиеся как есть, — это бренды
(`Cursor`, `VS Code`, `Google`), коды (`JSON`, `OAuth`, `MCP`, `REST`) и
примеры значений (`imap.example.com`, `sk-...`, `john.doe@example.com`).
Полный список — `ru-locale-exceptions.constant.ts`.

### 2. Дописаны 29 строк, которых нет в каталоге апстрима

Подписи части стандартных объектов и полей собираются в коде без `msg`,
поэтому экстрактор lingui их не видит, и ни в `en.po`, ни в `ru-RU.po` их
нет — а интерфейс их показывает. Это «Chat»/«Chats», «Short link»/«Short
links», «Chat thread participant(s)», поля ветки чата агента
(«Last message», «Participants», «Writers», «Subscribed», «Snoozed until»,
«Archived at», «Last read at», «Last mentioned at»), счётчики токенов
`agentTurn` («Input Tokens», «Cache Read Tokens», «Model ID» и соседние) и
поля короткой ссылки.

Сервер ищет перевод по хешу самой строки (`translateStandardLabel` →
`generateMessageId`), поэтому достаточно записи в каталоге. Записи помечены
комментарием `#. ONE-107` и добавлены парой в `ru-RU.po` и `en.po`, чтобы
`lingui extract` в будущем работал с ними как с одним целым.

Список собран не на глаз, а живой сверкой: метаданные стенда 2 запрошены с
заголовком `x-locale: ru-RU`, и всё, что вернулось латиницей, попало в
работу.

### 3. Пересобраны `locales/generated/*.ts`

Ядро читает не `.po`, а скомпилированный каталог. `yarn lingui:compile` в
этой ветке не запускался (в рабочем дереве нет `node_modules` — ставить весь
монорепозиторий ради компиляции каталога дороже, чем проверить результат),
поэтому скомпилированные каталоги пересобраны скриптом, а корректность
подтверждена двумя способами:

1. Самопроверка на существующих данных: для каждой уже переведённой строки
   пересчитанный идентификатор и скомпилированная форма сравнивались с тем,
   что лежит в репозитории. Совпало 2598 из 2598 (сервер) и 4499 из 4502
   (фронт; три расхождения — строки апстрима с нестандартным ICU, их никто
   не трогал).
2. Живая проверка: пересобранный серверный каталог подложен в контейнер
   стенда 2, сервер перезапущен, метаданные перечитаны с
   `x-locale: ru-RU`. «Chat» стал «Чат», «Short link» — «Короткая ссылка»,
   и так далее; латиницей остались только `ID`, `URL` и бренды.

### 4. Проверка полноты перевода

`packages/twenty-server/src/engine/core-modules/i18n/onema/` — отдельный
модуль форка, апстримный код он не трогает. Жёсткая проверка
(`__tests__/ru-locale.spec.ts`) падает, если:

- в русском каталоге появился пустой перевод не из списка исключений;
- перевод повторяет английский исходник (кроме брендов, кодов и примеров);
- в подписи объекта или поля есть латиница сверх списка слов-исключений
  (`ID`, `URL`, `UID`, `iCal`, `LinkedIn`);
- скомпилированный каталог разошёлся с `.po` — то есть перевод добавили, а
  каталог не пересобрали. Эта ошибка не видна глазами вообще: интерфейс
  просто остаётся английским.

Подробности — `onema/README.md`.

## Чего в этой ветке нет

- **Нового тега образа.** Его собирает `onema-image.yml` по тегу `onema-v*`;
  тег `onema-v2.45.0-onema5` ставит оркестратор после влития этого PR.
- **Переводов 36 других локалей.** Задача про русский; остальные языки
  остались ровно как в апстриме.
- **Правок строк в коде.** Ни один файл апстрима с текстом не переписан —
  только каталоги переводов и новый модуль проверки.

## Как проверить

```bash
yarn nx test twenty-server --testPathPattern=i18n/onema
```

Проверка читает каталоги с диска, сервер и база не нужны.
